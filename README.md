# cv-web · Hoja de vida web de Juan Sebastián Pulido Bojacá

Portafolio en forma de **mapa 3D**: el scroll mueve una cámara sobre un mapa antiguo y cada parada muestra una parte de la hoja de vida (perfil, experiencia, proyectos, conocimientos, IA aplicada y contacto). Español e inglés.

La versión actual está en [`favorita-2026-10-02/`](favorita-2026-10-02/). Para verla en local:

```bash
cd favorita-2026-10-02
python -m http.server 5190   # y abrir http://localhost:5190/index.html
```

Necesita internet (Three.js, fuentes y logos se cargan desde CDN). Está en construcción.
